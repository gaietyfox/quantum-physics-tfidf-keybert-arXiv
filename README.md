# Поиск характерных терминов в публикациях по квантовой физике: TF-IDF и KeyBERT

## О проекте

Проект посвящён анализу научных публикаций категории **Quantum Physics (`quant-ph`)** на платформе arXiv.

Цель работы - выделить слова и словосочетания, характерные для новых публикаций по квантовой физике, с помощью двух независимых методов:

- **TF-IDF**
- **KeyBERT**

После этого результаты двух методов сопоставляются, чтобы определить термины, найденные одновременно обоими подходами.

---

## Данные

В работе используется корпус из **100 научных публикаций**:

- **50 публикаций за июль 2026 года**
- **50 публикаций за предыдущие два года - с июля 2024 по июнь 2026 года**

Публикации относятся к категории:

`Quantum Physics (quant-ph)`

Для сравнительной выборки за предыдущие два года статьи распределяются по всему периоду, чтобы данные не концентрировались только в отдельных месяцах.

Для воспроизводимости случайной выборки используется фиксированный:

```python
RANDOM_SEED = 42
```

---

## Получение текстов

Для каждой публикации программа автоматически получает полный текст с arXiv.

Сначала используется HTML-версия статьи. Если она недоступна, программа пытается извлечь текст из PDF.

В текущем корпусе:

- 98 текстов были получены из HTML
- 2 текста были получены из PDF
- для всех 100 публикаций полный текст успешно прошёл контроль качества

Полные тексты сохраняются в корпусе и используются для дальнейшего анализа.

---

## Предобработка текста

Перед применением методов анализа тексты проходят базовую предобработку:

- перевод в нижний регистр
- удаление некоторых технических элементов LaTeX
- удаление команд LaTeX
- удаление отдельно стоящих чисел
- удаление лишних пробелов

При этом исходный полный текст статьи сохраняется отдельно без изменений.

---

## Метод 1. TF-IDF

Для статистического выделения характерных терминов используется:

```python
TfidfVectorizer
```

из библиотеки:

```python
scikit-learn
```

TF-IDF расшифровывается как:

**Term Frequency - Inverse Document Frequency**

Каждая из 50 июльских публикаций по очереди сравнивается с 50 публикациями за предыдущие два года.

Для анализа рассматриваются:

- отдельные слова
- словосочетания из двух слов
- словосочетания из трёх слов

Для этого используется:

```python
ngram_range=(1, 3)
```

Основной порог отбора:

```python
TFIDF_THRESHOLD = 0.6
```

То есть в основной результат сохраняются только термины с:

```text
TF-IDF score > 0.6
```

---

## Метод 2. KeyBERT

Второй метод используется независимо от TF-IDF.

KeyBERT применяется отдельно к каждой из 50 публикаций за июль 2026 года.

Используется модель:

```text
all-MiniLM-L6-v2
```

Анализируются слова и словосочетания длиной от одного до трёх слов:

```python
keyphrase_ngram_range=(1, 3)
```

Основной порог:

```python
KEYBERT_THRESHOLD = 0.4
```

Для одной статьи рассматривается до 500 наиболее релевантных кандидатов.

`top_n=500` является практическим ограничением текущей реализации: для некоторых публикаций даже 500-й кандидат может сохранять score выше 0.4.

---

## Сопоставление результатов

После независимого применения TF-IDF и KeyBERT результаты нормализуются:

- переводятся в нижний регистр
- удаляются лишние пробелы

После этого выполняется точное пересечение результатов.

Термин считается совпавшим только в том случае, если одновременно совпадают:

- `arxiv_id` публикации
- сам нормализованный термин

Таким образом, оба метода должны обнаружить один и тот же термин в одной и той же статье.

---

## Основные результаты

При исходных параметрах:

```text
TF-IDF score > 0.6
KeyBERT score > 0.4
```

получены следующие результаты:

| Показатель | Значение |
|---|---:|
| Публикаций за июль 2026 | 50 |
| Публикаций за предыдущие два года | 50 |
| Уникальных TF-IDF терминов | 2 |
| Уникальных KeyBERT терминов | 14 990 |
| Уникальных терминов в пересечении | 0 |
| Статей хотя бы с одним точным совпадением | 0 |

При исходном пороге TF-IDF > 0.6 были выделены только два уникальных термина, что показывает высокую строгость данного порога.

---

## Анализ влияния порога TF-IDF

Дополнительно была выполнена проверка чувствительности результата к изменению порога TF-IDF.

| Порог TF-IDF | TF-IDF терминов | Совпавших терминов | Статей с совпадением |
|---:|---:|---:|---:|
| 0.6 | 2 | 0 | 0 |
| 0.5 | 6 | 1 | 1 |
| 0.4 | 14 | 1 | 1 |
| 0.3 | 47 | 3 | 3 |
| 0.2 | 120 | 8 | 6 |
| 0.1 | 611 | 52 | 25 |

Снижение порога TF-IDF приводит к увеличению числа отобранных терминов и количества пересечений с результатами KeyBERT.

Это не означает, что более низкий порог является автоматически более правильным. Дополнительный анализ показывает, насколько результаты чувствительны к выбранному пороговому значению.

---

## Основной вывод

TF-IDF и KeyBERT анализируют текст разными способами.

TF-IDF позволяет выделять статистически характерные для документа слова и словосочетания относительно сравнительного корпуса.

KeyBERT используется для извлечения ключевых слов и фраз, семантически связанных с содержанием конкретной статьи.

При исходных строгих параметрах точного пересечения между двумя методами обнаружено не было.

Дополнительный анализ показал, что количество совпадений существенно зависит от выбранного порога TF-IDF.

## Ограничения

В текущей реализации необходимо учитывать несколько ограничений:

- объём корпуса составляет 100 публикаций
- сравнение терминов основано на точном строковом совпадении
- результат зависит от выбранных пороговых значений
- для KeyBERT используется ограничение `top_n=500`
- дополнительный поиск наиболее раннего упоминания термина может быть выполнен только в пределах сформированного корпуса, а не всего архива arXiv
